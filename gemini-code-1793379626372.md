## 📑 Especificación Léxica

A continuación se detalla la tabla de tokens soportados por el lenguaje **IoT-Script**:

| Token | Expresión Regular (ER) | Descripción | Ejemplo Aceptación | Ejemplo Rechazo |
| :--- | :--- | :--- | :--- | :--- |
| `KW_SI` | `\bsi\b` | Palabra reservada condicional | `si` | `SI`, `Si` |
| `KW_ENTONCES` | `\bentonces\b` | Cierre de condición | `entonces` | `Entonces` |
| `KW_SENSOR` | `\bsensor\b` | Declaración de sensor | `sensor` | `sensors` |
| `KW_ACTUADOR` | `\bactuador\b` | Declaración de actuador | `actuador` | `actua` |
| `IDENTIFICADOR`| `[a-zA-R_][a-zA-R0-9_]*` | Nombre de variable/dispositivo | `temp_int`, `_s1` | `1temp`, `temp@` |
| `NUMERO_ENT` | `0 \| [1-9][0-9]*` | Constante entera | `0`, `45`, `1024` | `045`, `00` |
| `NUMERO_DEC` | `(0 \| [1-9][0-9]*)\.[0-9]+` | Constante decimal | `36.5`, `0.01` | `.5`, `12.` |
| `MAYOR_IGUAL` | `>=` | Operador relacional | `>=` | `>`, `=` |
| `MENOR_IGUAL` | `<=` | Operador relacional | `<=` | `<`, `=` |
| `ASIGNACION` | `=` | Operador de asignación | `=` | `==`, `:=` |
| `PUNTO_COMA` | `;` | Delimitador de instrucción | `;` | `,` |
| `CADENA` | `"([^"\\]\|\\.)*"` | Cadena de texto literal | `"Alerta Temp"` | `'Alerta'` |
